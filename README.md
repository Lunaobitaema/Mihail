# mihail — репетитор 7 класу

Статичний сайт за програмою 7 класу НУШ (Україна): алгебра, геометрія, фізика, історія.

- для кожного предмета — смуга тем на рік (пройдено / зараз / попереду);
- поточна тема: теорія, наочні схеми та інтерактив, приклади з покроковими розв'язками й поясненням «чому», «Перевір себе», цікаві факти;
- журнал домашки з датами «задано» і «здати до» (зберігається в браузері; резервну копію можна перенести на інший пристрій з головної сторінки).

Увесь сайт — один файл `index.html`, без збірки та залежностей.

## Публікація на GitHub Pages

Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
Сайт з'явиться за адресою `https://<логін>.github.io/mihail/`.

## Як додати тему

Дані тем — на початку скрипта в `index.html` (об'єкт `S`). Кожна тема має поля `t` (назва), `m` (місяць), `hook`, `theory`, `ex` (приклади з кроками), `quiz`, `fact`, `visual`.
Поле `cur` у предметі — номер поточної теми (з нуля).
